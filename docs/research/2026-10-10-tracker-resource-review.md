## Decisions implemented

Resource access and setup are prominent across the reviewed pages. Nexaly articles must accurately distinguish an on-page example, a browser tool and a paid planner. Corrected the remaining Content Calendar and Homeschool Attendance free-download links and workbook-specific claims, including metadata. Added copyable order-log columns plus partial-shipment/cancellation setup guidance. Added a separate unconfirmed-deadline workflow for assignments, so readers do not invent dates to satisfy tool inputs. Existing layouts and checkout remain protected by repository core-lock checks.

Next measurement: compare US impressions, query positions and clicks after Search Console has processed the release. Do not infer improvement from publication or technical checks alone.
