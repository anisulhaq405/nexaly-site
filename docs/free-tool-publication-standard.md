# Free tool page publication standard

Apply this standard to each completed tool in the 50-tool collection. Do not publish empty tool URLs or advertise unfinished functions.

- Give each tool its own stable descriptive URL and one clear H1.
- Show a relevant screenshot of the actual working tool on its directory card and detail page. Use fictional sample data, a visible caption, descriptive alt text and explicit dimensions. Compress images; lazy-load below-the-fold directory previews.
- Put an immediate free-use CTA and working inputs before the complete guide. Keep inputs usable with labels, keyboard focus, validation and responsive layouts.
- Explain purpose, features, input fields, units, workflow, formulas, worked examples, limitations, saving, export formats and relevant questions in visible HTML.
- Use specific long-tail wording only where it describes the function naturally. Do not invent keyword volume or demand evidence.
- Link the tool from its category directory and relevant existing articles or product guides. Link back to those resources in context. Use descriptive anchor text and avoid linking to every unrelated tool.
- Keep the primary CTA focused on using the free tool. Use a separate optional CTA to a relevant paid product and its guide, explaining compatibility accurately.
- Include unique title and description, self-canonical, sitemap entry, breadcrumbs and truthful WebApplication data. Structured data must describe visible functionality; never fabricate ratings.
- Keep calculation reports free of navigation, guides and sales CTAs when printed.
- Verify calculations, input errors, saving/import/export, print output, image delivery, links and phone/tablet/desktop layout before publication.
- SEO fundamentals apply to AI search too. Crawlable text, useful images, clear links and accurate schema support discovery; indexing, ranking and AI citations cannot be promised.

## October 6 category release

The collection has eight available tools, one per category. Each worksheet uses a distinct scoped palette and visual treatment. Shared site navigation, product prices, checkout links and paid applications remain outside these theme styles. The inventory tool keeps teal; new tools use navy, purple, orange, blue, green, rose and amber.

The attendance log allows 400 entries to cover an annual record with some repeated subject dates; the other new worksheets allow 100. Task-specific calculations live in `assets/js/small-tools-models.js`. Saving and exports are explicit, with separate storage keys and versioned backups per tool. No entered worksheet fields are added to analytics or sent to another application.
