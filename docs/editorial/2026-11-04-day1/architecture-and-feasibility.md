## O053 Financial Statement Builder — spike started, Day9 acceptance

The original query says “financial statement generator.” A generic profit card does not fulfill that intent. The internal `prototypes.cjs` proves a cents-based operating/cash/receivables/payables bridge against the financial journal example. It is **not** a complete balance sheet, income statement and cash-flow statement, and is not publicly linked.

Candidate build: a local browser worksheet with explicit opening balances, period movements, assets/liabilities/equity reconciliation, income/cash classifications, visible imbalance errors, versioned JSON backups and static export. No bank integration, tax filing, standards certification, hosted accounts, paid model API or user-entry transmission.

Day2 decision gate: determine whether a clearly bounded management-statement builder can satisfy the intended query without implying formal accounting compliance. Verify opening balance/equity, classifications, noncash entries and rounding; otherwise consolidate O053 into existing balance-sheet/cash/projection owners with its original ID and reason retained. Do not publish a “generator” page containing only prose.

Dependencies: original models and tests, field/period definitions, export/import validation, responsive UI, print QA and official explanatory sources. Integer cents spike passes normal and invalid-input checks. Production interactions remain unbuilt and scheduled for later acceptance.

## O117 Business Flyer Draft Tool — spike started, Day10 acceptance

The source phrase “ai flyer generator” implies capabilities the site must not invent. The internal spike creates deterministic plain text from bounded business, offer, audience and next-action fields. It uses no model, credits, images, network or private data store.

Day2 decision gate: build an honestly labeled rule-based flyer draft tool only if that output satisfies a distinct planner use case; otherwise consolidate or exclude the AI-generator intent with a documented reason. If building, implement editable layout, print/download, safe text rendering, versioned backup and no invented offers, testimonials or business contact details. It must never be advertised as AI-powered without an actual verified model workflow.
