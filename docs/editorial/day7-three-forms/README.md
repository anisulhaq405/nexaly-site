# Three original free business forms

Authorized scope: build and publish Expense Report, Purchase Requisition and Customer Order Form together. USA/Tier 1/2 readers; Free Planners category; /tools/ convention.

Each has an original ten-row browser worksheet, XLSX Blank/Filled example/Instructions, static two-page US Letter landscape PDF and actual rendered workbook previews. No paid product behavior, checkout or pricing changes. Financial scope is entered amounts and reimbursement/order arithmetic, without tax treatment, legal approval or accounting certification. All examples are fictional.

Primary background: IRS supporting business records and Oracle purchase-order attributes, linked in the relevant page. No third-party templates copied; no paid SEO calls.

Checks: 25 workbook mutation/blank/export-import cases; 68 model/backup/CSV cases; 33 DOM cases. PDF and worksheet renders reviewed. Native Microsoft Excel/Sheets, physical printing and real-phone behavior are not certified.

Reproduction: prepare-config.py; build-workbooks.mjs using bundled Artifact Tool (NEXALY_SITE_ROOT optional); build-pdfs.py; build-pages.py. The latter is a one-time publication script: do not rerun directory/context inserts without removing those inserts first. Run scripts/seo-build.py and test-business-forms*.cjs. Config: assets/js/business-forms-configs.json. Browser JSON and workbook are separate formats.
