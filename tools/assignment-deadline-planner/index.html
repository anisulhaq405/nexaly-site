What this free planner does

  • Assignment, course, exact local due time and next-step notes.
  • Estimated versus worked hours without automatic completion assumptions.
  • A deadline-sorted report using the reference time and timezone you enter.
  • Up to 100 editable entries, explicit device saving, JSON backup, CSV and browser PDF printing.

How to use it

  1. Name the plan and enter the date and time you want to check against. Label the single timezone used for every deadline, such as America/New_York.
  2. Add each assignment and course. Copy its deadline from the official instructions and convert it to your chosen timezone yourself if necessary.
  3. Enter estimated total work and hours already spent. Mark Completed only when you have confirmed completion; use next-step notes for subtasks or submission details.
  4. Calculate, check overdue rows and review remaining effort. Update the reference time on each visit; it does not advance automatically in a saved report.

How the calculation works

Remaining estimated hours = max(0, estimated hours − hours already worked). A row marked Completed contributes zero remaining hours. An unfinished assignment is overdue when its due time is earlier than the entered reference time; equal times show Due now.

Worked example with fictional data

A fictional economics essay has a 3-hour estimate and 1 hour already worked, so 2 estimated hours remain. At a reference time of October 6 at 09:00, a deadline of October 9 at 17:00 is Upcoming. After the reference passes the deadline, the unfinished row is Overdue. Spending all 3 estimated hours does not automatically mark the essay Completed.

Assumptions and common mistakes

This assignment deadline planner does not connect to a learning portal, submit work, verify grades or provide background reminders. All date-times are compared as wall-clock values in the same timezone label; no automatic timezone or daylight-saving conversion occurs. Remaining hours are an estimate, not a guarantee of finishing before the deadline.

Keep the official cutoff and submission receipt in your course system. A task can need more time than its first estimate: increase the estimate when new information appears instead of assuming zero remaining hours means finished. The notes field can hold a short sequence such as outline, draft and references; each assignment remains one editable row.

Save, restore and export

Add entry creates another record. Edit any field directly or use Remove entry to delete a row. Changing inputs clears the previous report so it cannot be mistaken for current results. Choose Calculate / review results again when your changes are ready.

Save on this device keeps an editable worksheet in this browser only. On a later visit in this browser, your saved worksheet loads automatically. Restore device save can also reload the last save after you confirm replacement. Saving drafts is allowed, but a report requires valid, complete inputs. Download backup creates a versioned JSON file for the same tool. Import backup shows the worksheet label and row count before replacing current work; it does not change the device save until you press Save.

Download CSV exports the settings, summary, row details and calculation notes. CSV is for spreadsheet review; it cannot restore this worksheet. Print / Save PDF recalculates the current entries and opens your browser’s print dialog. Choose Save as PDF where supported. The report excludes navigation, guides and product CTAs. Clear data removes the current worksheet and its device save after confirmation; keep a backup first if needed.

Frequently asked questions

Will the planner alert me when a deadline arrives?

No. It checks deadlines when you calculate against your reference time. Use a separate calendar or reminder if you need an alert.

What happens if I work more hours than estimated?

Remaining estimated hours stop at zero. The row keeps its chosen status and asks you to review an exhausted estimate if it is unfinished.

Can I mix deadlines from different timezones?

Convert them to one timezone before entering them. The timezone field labels the plan; it does not convert timestamps.

Is this tool free, and does it sync between devices?

All worksheet, saving and export features are free without an account. There is no cloud synchronization. Transfer a JSON backup to another device and import it into this same tool.
