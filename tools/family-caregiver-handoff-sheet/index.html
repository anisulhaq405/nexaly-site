What this free tool does

  • Pending and In progress tasks stay visible as open work.
  • A dedicated open-tasks table gives the next helper a focused handoff.
  • Recipient preferences, factual observations and agreed contact details are optional.
  • Up to 100 editable entries, explicit device saving, JSON backup, CSV and browser PDF printing.

How to use it

  1. Use a recipient nickname, visit date and the outgoing and next helper names. Add agreed contact details only if they are needed in the report.
  2. Add each agreed household or coordination task, its status and the person to follow up. Use a next-action note for work that remains open.
  3. Write factual observations or preferences that help the next helper understand the arrangement. Check the wording with the recipient where appropriate.
  4. Review the report, download a copy and share it directly with the agreed helper. Confirm receipt outside this tool.

How the calculation works

Open handoff tasks = all agreed tasks − tasks marked Completed. Pending and In progress remain open. The report lists open work before completed work and repeats it in a dedicated handoff table. Status is entered manually; no task is inferred to be done because a date has passed.

Assumptions and common mistakes

This family caregiver handoff sheet supports organization only. It does not assess health, recommend care, provide medication doses, contact helpers or handle emergencies. Clinical instructions belong in an appropriate record and qualified care process. A task marked Completed means someone recorded that status, not that the tool verified it.

Keep each task specific and give open work one clear follow-up person. Avoid using observations as a diagnosis. A missing next-action note triggers a reminder in the report while the task still remains pending. On shared devices, use nicknames and consider downloading a copy rather than saving private details in the browser.

Save, restore and export

Add entry creates another record. Edit any field directly or use Remove entry to delete a row. Changing inputs clears the previous report so it cannot be mistaken for current results. Choose Calculate / review results again when your changes are ready.

Save on this device keeps an editable worksheet in this browser only. On a later visit, choose Restore device save and confirm replacement. Saving drafts is allowed, but a report requires valid, complete inputs. Download backup creates a versioned JSON file for the same tool. Import backup shows the worksheet label and row count before replacing current work; it does not change the device save until you press Save.

Download CSV exports the settings, summary, row details and calculation notes. CSV is for spreadsheet review; it cannot restore this worksheet. Print / Save PDF recalculates the current entries and opens your browser’s print dialog. Choose Save as PDF where supported. The report excludes navigation, guides and product CTAs. Clear data removes the current worksheet and its device save after confirmation; keep a backup first if needed.

Frequently asked questions

What if a task was started but not finished?

Mark In progress and add the next action. It remains open for the next helper.

Does the next helper receive this automatically?

No. Share the downloaded report yourself and confirm they received it.

Can I use this for medication instructions?

This worksheet is for organizational handoffs. It does not create or verify medication instructions; keep clinical information in the appropriate care process.

Is this tool free, and does it sync between devices?

All worksheet, saving and export features are free without an account. There is no cloud synchronization. Transfer a JSON backup to another device and import it into this same tool.
