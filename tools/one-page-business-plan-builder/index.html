What this worksheet does

Prints the core customer, problem, offer and economics with an evidence log. A one-page summary is compact with up to three short assumptions; additional or long entries can require more pages. Supported is a user-entered status, not independent proof. This is not a funding application.

Keep up to 20 editable entries. The worksheet runs in your browser and does not send its entries to another service. The calculations use the inputs you provide; currency selectors label amounts without conversion.

How to use it

  1. Set a descriptive worksheet name and complete the settings for your planning period.
  2. Add one entry per record. Use consistent units and keep the evidence behind your assumptions.
  3. Calculate and inspect the report, including any review notes. Change an input and calculate again to replace the old result.
  4. Save an editable backup before changing a scenario. Use the related guide below for the wider operating workflow.

Save, restore and export

Save on this device writes an explicit save to this browser; it does not download a file or sync across devices. Clearing browser storage can remove it. Download backup keeps an editable JSON file for this exact worksheet. Import previews the backup before replacing current entries; save again if you want to replace the device save. CSV contains the calculated report, not an editable import format. Print / Save PDF opens the browser print dialog; choose Save as PDF where available.

Questions and limits

Is the example my result?

No. It is fictional data. Replace its assumptions with your own records, then calculate again.

Does saving share my worksheet?

No. Device saves belong to this browser. Move an editable worksheet with its JSON backup and keep sensitive information out of a shared device.

Does a report establish that my plan is correct?

No. Arithmetic can be consistent while the input assumptions are wrong. Keep evidence, review the scope described above and check any decisions against your real records.
