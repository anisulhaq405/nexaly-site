What this free planner does

  • A five-part time budget with one row per client or project.
  • Free capacity and overbooked hours shown without hiding negative results.
  • Capacity booked percentage, with a clear zero-capacity state.
  • Up to 100 editable entries, explicit device saving, JSON backup, CSV and browser PDF printing.

How to use it

  1. Enter planned working hours for the week before deducting leave. Add the week label and starting date for your report.
  2. Separate leave, admin and buffer hours. Count each hour once; do not subtract leave again if you already removed it from working hours.
  3. Add the delivery hours promised to each client or project. Include revisions and meetings here only if they belong to client delivery in your records.
  4. Calculate. Review free hours, the percentage booked and any overbooking message before accepting another commitment.

How the calculation works

Delivery capacity = planned working hours − leave − admin − buffer. Booked delivery is the sum of project rows. Free capacity = delivery capacity − booked delivery. Capacity booked = booked delivery ÷ delivery capacity × 100; no percentage is calculated when delivery capacity is zero.

Worked example with fictional data

A fictional freelancer plans 40 working hours, no leave, 8 admin hours and 4 buffer hours. Delivery capacity is 28 hours. A 20-hour project leaves 8 free hours. Adding another 12-hour project makes booked delivery 32 hours and free capacity −4 hours: the week is overbooked by 4 hours.

Before you save your plan

  • Set aside admin, leave and buffer time before you promise client delivery hours.
  • Check overbooked weeks against your project calendar; available hours do not guarantee project profitability.

Check a new project against the time already promised

This fictional freelancer plans a 40-hour week with four hours of leave, six admin hours and four unbooked buffer hours. Delivery capacity is 26 hours. Existing clients need 18 hours; a proposed 10-hour project would take bookings to 28 hours.

  1. Include revisions and delivery meetings in the relevant project estimate. Use consistent categories so those hours are not also subtracted as admin.
  2. Check the calendar: eight free hours scattered across short gaps may not support a task requiring a continuous work block.
  3. Recalculate after an agreed scope or date change. Do not remove promised client hours simply to make capacity positive.
  4. Save a dated JSON backup after agreeing the week; use CSV or PDF to share the report.

Assumptions and common mistakes

This free freelancer capacity planner measures a time budget. It does not estimate project fees, profit, employee availability or whether an assignment is realistic. Leave, admin and buffer together cannot exceed planned working hours. Booked delivery may exceed capacity so you can see the problem; the tool will not silently cap it.

Keep buffer separate from a named client commitment. Decide where you record project meetings and stick to that convention. If several clients share one work block, allocate that block across the rows rather than entering its full duration for each client. Decimal hours are supported: 1.5 hours means 90 minutes, not 1 hour 5 minutes.

Save, restore and export

Add entry creates another record. Edit any field directly or use Remove entry to delete a row. Changing inputs clears the previous report so it cannot be mistaken for current results. Choose Calculate / review results again when your changes are ready.

Save on this device keeps an editable worksheet in this browser only. On a later visit in this browser, your saved worksheet loads automatically. Restore device save can also reload the last save after you confirm replacement. Saving drafts is allowed, but a report requires valid, complete inputs. Download backup creates a versioned JSON file for the same tool. Import backup shows the worksheet label and row count before replacing current work; it does not change the device save until you press Save.

Download CSV exports the settings, summary, row details and calculation notes. CSV is for spreadsheet review; it cannot restore this worksheet. Print / Save PDF recalculates the current entries and opens your browser’s print dialog. Choose Save as PDF where supported. The report excludes navigation, guides and product CTAs. Clear data removes the current worksheet and its device save after confirmation; keep a backup first if needed.

Frequently asked questions

How much buffer should a freelancer keep?

You enter your own buffer based on the work and uncertainty you expect. The calculator does not prescribe a universal percentage.

Why can free capacity be negative?

A negative number means your booked hours exceed delivery capacity. The absolute value is the number of overbooked hours.

Does 100% booked mean all working hours are client work?

No. The percentage uses delivery capacity after leave, admin and buffer, not total planned working hours.

Is this tool free, and does it sync between devices?

All worksheet, saving and export features are free without an account. There is no cloud synchronization. Transfer a JSON backup to another device and import it into this same tool.
