Typed review status is a manual record. It does not verify identity, approve spending, send an order or move money.

How to use the purchase requisition

  1. Describe the need. Enter a unique request reference, requester, department, need-by date and business reason. A request should explain the work that will be delayed if the items are unavailable.
  2. List items in buying units. Use quantity and estimated price for the same unit. Twenty each at $6 is different from twenty boxes at $6. Add a suggested supplier and quote reference when known.
  3. Add estimated charges. Enter shipping and tax as amounts in the selected currency. These are estimates you supply; the form does not look up supplier prices or tax rates.
  4. Compare with the available budget. Enter the budget available for this request. Negative headroom calls for a revised request or a budget decision. Positive headroom is only a cost comparison.
  5. Record the separate approval. The reviewer enters a decision and fixed review date under your process. If the request proceeds, create the supplier PO separately and add its reference. Retain both versions.

Worked example: check the result

Request 20 filters at $6 each and 5 pairs of gloves at $8, plus $10 shipping and $0 entered tax. The estimate is $120 + $40 + $10 = $170. Against an entered $160 budget, headroom is -$10. Reducing filters to 18 changes the estimate to $158 and headroom to $2; neither result approves the purchase.

Load the fictional example above to inspect the calculation. The Excel Filled example tab and the second PDF page use the same inputs. A blank form stays incomplete until the required rows and adjustment amounts are supplied. Enter 0 for a charge that does not apply.

Requisition, purchase order and invoice

The requisition records an internal need. A purchase order records the order issued to a supplier. An invoice is a request for payment. Keep separate references so an internal estimate does not become an unintended supplier order.

Keep budget fit separate from approval

The example is $10 over the entered budget. Changing the quantity to 18 leaves $2 headroom, while the manual status remains Draft. The worksheet does not check spending authority, existing commitments or departmental policy.

What to do when a quote changes

Update the estimated price and quote reference before review, then save a version. If a supplier order already exists, handle the change through that purchasing process rather than replacing the historical request.

Save, reopen and print

In the browser, choose Save on this device deliberately; entries are not saved automatically. Restore device copy retrieves that browser’s last saved version. Clearing browser storage or using a private window can remove it. Download JSON backup before switching devices or closing an important session, and store files containing customer or employee details appropriately.

For Excel, save a separate .xlsx per request. Reopen it and change one value to check recalculation before using it operationally. Select A1:H33 on the required tab, use landscape Print Selection and fit to one page. Column J contains row review messages outside that print area; fix them first. Ten rows are provided: do not extend the form without checking formulas and total ranges.

The downloadable PDF has a fixed layout. Browser Print / Save PDF uses your browser’s print dialog and may span more than one page; check every row and field in preview. The workbook has been recalculated and export/import tested with Artifact Tool. Native Excel, Google Sheets, physical printer output and real-phone behavior have not been certified.

Frequently asked questions

Is this an employee hiring requisition?

No. This resource requests goods or services for an internal purchase. It does not manage recruitment or employee headcount.

Does an Approved status issue a purchase order?

No. Status is a manual record only. The worksheet neither verifies the approver nor sends an order. Prepare and review a separate PO.

Can I use it for services?

Yes, when quantity and unit describe the service clearly, such as 2 hours at a quoted hourly amount. Keep the agreed scope and quote reference with the request.
