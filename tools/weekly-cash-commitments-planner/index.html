What this free planner does

  • Seven dated daily balances, plus opening and closing cash.
  • A confirmed-receipts scenario that still includes every payment.
  • Editable transactions with a certainty label and clear inclusion status.
  • Up to 100 editable entries, explicit device saving, JSON backup, CSV and browser PDF printing.

How to use it

  1. Choose the first day of your week, one currency and the cash available at the start. Use a balance checked against your own records.
  2. Add a separate receipt or payment for each expected cash movement. Use its cash date, not the invoice issue date.
  3. Choose All planned receipts or Confirmed receipts only. Calculate, then check each daily closing and any negative balance.
  4. Update dates or certainty when information changes. Recalculate and download a report before discussing the week with your team.

How the calculation works

Closing cash = opening cash + included receipts − all payments. Each day starts with the previous day’s closing cash. The lowest balance considers opening cash and each day-end closing, not the order of transactions within a day.

Worked example with fictional data

A fictional shop starts the week with USD 1,000. It expects a confirmed USD 400 collection on Tuesday and a USD 600 supplier payment on Thursday. Closing cash is 1,000 + 400 − 600 = USD 800. If that receipt is changed to Expected and you select Confirmed receipts only, closing cash becomes USD 400; the payment is still included.

Before you save your plan

  • Review the dates cash will actually move, then check the lowest daily balance rather than only the week-end total.
  • Keep planned receipts separate from confirmed receipts and save a fresh backup for each week.

Assumptions and common mistakes

This weekly cash flow planner is a scenario worksheet. It does not retrieve bank balances, predict customer payment behavior, transfer money or give borrowing advice. A positive week-end balance can still hide a negative balance earlier in the week. Same-day transaction timing is not modeled. All cash dates must fall within the seven-day window, and all amounts must use one currency. Changing the currency label does not convert values.

Enter gross cash amounts consistently. If fees or taxes create separate cash movements, record those as separate payments using the dates and amounts from your own records. Do not enter a customer invoice and its expected receipt twice. Use a new backup for each week so a later edit does not replace your historical record.

Save, restore and export

Add entry creates another record. Edit any field directly or use Remove entry to delete a row. Changing inputs clears the previous report so it cannot be mistaken for current results. Choose Calculate / review results again when your changes are ready.

Save on this device keeps an editable worksheet in this browser only. On a later visit, choose Restore device save and confirm replacement. Saving drafts is allowed, but a report requires valid, complete inputs. Download backup creates a versioned JSON file for the same tool. Import backup shows the worksheet label and row count before replacing current work; it does not change the device save until you press Save.

Download CSV exports the settings, summary, row details and calculation notes. CSV is for spreadsheet review; it cannot restore this worksheet. Print / Save PDF recalculates the current entries and opens your browser’s print dialog. Choose Save as PDF where supported. The report excludes navigation, guides and product CTAs. Clear data removes the current worksheet and its device save after confirmation; keep a backup first if needed.

Frequently asked questions

Which dates belong in a weekly cash commitments planner?

Use the day money is expected to enter or leave cash. This can differ from an invoice date or expense recognition date.

What changes in the confirmed-receipts scenario?

Expected receipts are excluded. All payments remain included, even payments labeled Expected. The report shows the rule and each transaction’s inclusion status.

Can I use it for a longer forecast?

This worksheet covers seven calendar days. For a longer workflow, review the CashFlow 13 OS guide rather than combining week totals without checking opening balances.

Is this tool free, and does it sync between devices?

All worksheet, saving and export features are free without an account. There is no cloud synchronization. Transfer a JSON backup to another device and import it into this same tool.
