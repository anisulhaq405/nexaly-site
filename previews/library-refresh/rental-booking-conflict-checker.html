What you can do

  • All concurrent bookings checked together, not only in pairs.
  • Half-open intervals allow exact back-to-back bookings when the buffer is zero.
  • Conflict quantities and affected references shown for each interval.
  • Up to 100 editable rows, explicit device saving, JSON backup, CSV and browser PDF printing.

How to use this planner

  1. Review one resource group with a consistent total capacity.
  2. Convert booking times to UTC before entering them; include the full dates for overnight bookings.
  3. Enter each reference, start/end and reserved quantity, then set the turnaround buffer.
  4. Calculate and resolve every over-capacity interval in your actual booking records.

How the result works

For one equipment group, place quantity-change events at each booking start and buffered end. Sum all active quantities between consecutive event times. Every interval above capacity is a conflict, including three or more overlapping reservations. Same-time releases and starts are combined before evaluating the next interval.

Worked example with fictional data

Capacity is 2 projectors. Booking A holds 2 until 12:00 plus 30 minutes turnaround. Booking B starts at 12:15 for 1. From 12:15 to 12:30 UTC, 3 are reserved against capacity 2: a 1-unit conflict.

Limits to keep in mind

Enter every timestamp in UTC (not local time). The calculation makes no timezone conversion. Bookings occupy [start, end + turnaround); at the exact available-again time capacity is released. This is a capacity check, not a booking system or equipment safety approval.

Review the result before acting

  1. Resolve quantity conflicts before promising a rental slot.
  2. Allow enough turnaround for your own inspection and preparation process.
  3. Check the source booking timezone carefully; UTC input keeps daylight-saving ambiguity outside the calculation.

Save, restore and export

Add entry creates another record. Edit any field directly or use Remove entry to delete a row. Changing inputs clears the previous report so it cannot be mistaken for current results. Choose Calculate / review results again when your changes are ready.

Save on this device keeps an editable worksheet in this browser only. On a later visit, choose Restore device save and confirm replacement. Saving drafts is allowed, but a report requires valid, complete inputs. Download backup creates a versioned JSON file for the same tool. Import backup shows the worksheet label and row count before replacing current work; it does not change the device save until you press Save.

Download CSV exports the settings, summary, row details and calculation notes. CSV is for spreadsheet review; it cannot restore this worksheet. Print / Save PDF recalculates the current entries and opens your browser’s print dialog. Choose Save as PDF where supported. The report excludes navigation, guides and product CTAs. Clear data removes the current worksheet and its device save after confirmation; keep a backup first if needed.

Use a personal browser for private records and keep important backups separately. Entered worksheet fields are not included in our planner-action analytics.

Frequently asked questions

Can I enter local timestamps?

No. These fields are explicitly UTC. Convert local times before entering them, especially around daylight-saving changes. The worksheet does not resolve ambiguous local times.

Can I check different equipment groups together?

Use a separate worksheet/backup per group. A shared pool must contain interchangeable units; unrelated assets do not share capacity.

Is it free, and can I move my work to another device?

All worksheet features are free without an account. Save on this device keeps data in this browser; use an editable JSON backup to transfer it. CSV and PDF are reports, not import files. There is no cloud sync or background monitoring.
