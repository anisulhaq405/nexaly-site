Frequently asked questions

How does the draw calculator work?

It uses the cash, obligations, reserves and cash buffer you enter to estimate an unprotected balance, then applies your chosen safety factor to calculate a planning ceiling.

Can I plan payments for more than one owner?

Yes. Create separate owner records and payment plans. Active allocation shares must total 100% for the planner to calculate allocations.

Where is my data saved?

The app saves records in the browser profile you use to open it. Export a JSON backup before switching devices or clearing browser data.

Does it convert currencies?

Choose one of 36 base currencies before entering financial records. Amounts are tracked in that currency and exchange rates are not applied.

What does the download include?

The ZIP contains the standalone HTML planner and a quick-start guide. Extract the files and open the HTML file in a modern desktop browser.
