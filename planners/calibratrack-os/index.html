What's included

  • Instrument register and calibration schedule
  • Calibration events and certificate references
  • Out-of-tolerance reviews and corrective actions
  • Service work orders, downtime and estimated costs
  • Vendor turnaround and spending reports
  • JSON backup and restore; CSV instrument export

Download and compatibility

The customer download contains a self-contained HTML app and a Read Me First guide. Extract the ZIP and open the HTML file in a modern desktop browser. Records stay in that browser; save JSON backups regularly, especially before clearing browser data or moving devices. Choosing a currency changes the display format and does not convert exchange rates.

Important limits

CalibraTrack OS is an internal recordkeeping and management aid. It does not certify ISO or regulatory compliance, approve calibration results, or authorize instrument use or return to service. Qualified personnel remain responsible for those decisions.
